# FA4-Sorgu
This is the new Osint tool from py

## Kurulum (Installation)
1. Projeyi klonlayın:
   ```
   git clone https://github.com/A646/FA4-Sorgu
   ```
2. Gerekli bağımlılıkları yükleyin:
   ```
   pip install colorama
   ```
   (Eğer başka bağımlılıklar varsa, requirements.txt dosyasını kontrol edin veya ekleyin.)

## Çalıştırma (To Run)
1. Proje dizinine gidin:
   ```
   cd FA4-Sorgu
   ```
2. Osint.py dosyasını çalıştırın:
   ```
   python Osint.py
   ```
